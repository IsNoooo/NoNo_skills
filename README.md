# NoNo_skills

可复用的AI工作流技能。目前收录一个Skill：**专利评估定向修订**（`patent-evaluation-revision`）。

## 专利评估定向修订

根据专利预评估报告、专利文稿和对比文献全文，帮助AI找出卡分位置，制定有依据的修改计划，完成获授权的文稿修订，并解释复评变化。

适用于以 **D级或C级提升至B级** 为目标的修订任务，以及相似专利比对、修改建议审阅和升降星复盘。实际等级以复评为准，平台评级不等于专利授权结果。

[查看完整技能说明](skills/patent-evaluation-revision/SKILL.md)

### 核心流程

1. **确认版本**：核对报告实际展示的权利要求与底稿，检查误拆、遗漏和编号错位。
2. **定位问题**：区分分项星级、权项相关度和整体近似度，按技术内容对齐新旧权项。
3. **核对全文**：找出对方已记载的机制、本案已有但表达不清的内容，以及尚需补充的设计。
4. **定点修订**：写清触发条件、具体处理和输出差异，核对权项引用与说明书支撑。
5. **检查文稿**：同步摘要、说明书、实例和附图，验证技术逻辑及版式，保留可恢复版本。
6. **复评归因**：同时解释改善、不变和恶化的项，不把一次成功推导成固定评分公式。

## 准备哪些材料

- 专利文稿，最好提供可编辑的DOCX，并说明当前版本。
- 本次评估报告；如需比较，再提供此前报告及对应稿件。
- 报告引用的关键对比专利全文；清晰图片也可使用，重要段落需核对原图。
- 是否已正式提交申请，以及当前只需分析、修改计划，还是允许修改文稿。

已有材料可直接沿用。评分规则、实现代码或实验数据尚未取得时，应如实说明，不必编造补齐。

**请勿把未公开专利原稿、评估报告、联系方式或账号凭据提交到这个公开仓库。** 在本地任务中提供必要材料，并按实际权限使用。

## 安装

1. 下载或克隆本仓库。
2. 将整个 `skills/patent-evaluation-revision` 文件夹复制到本机Codex个人技能目录。当前官方用户级目录为 `~/.agents/skills/`；如果本机已有明确配置的技能目录，请沿用该目录。
3. 保留 `references/` 和 `agents/`，不要只复制 `SKILL.md`。已有同名Skill时，先备份再更新，避免同时安装重复版本。

安装后的入口示例：

```text
~/.agents/skills/patent-evaluation-revision/SKILL.md
```

Codex会检测技能变更；如果列表未更新，可重启Codex。目录与调用方式以[官方技能文档](https://learn.chatgpt.com/docs/build-skills)为准。

## 使用示例

### 先分析，不改文稿

```text
使用 $patent-evaluation-revision。
请对照这些专利文稿和评估报告，解释卡分原因并制定定点修改计划。
当前只分析，不修改DOCX，不上传材料或付费送评。
```

### 按确认的计划修改

```text
使用 $patent-evaluation-revision。
以这份文稿为底稿，按已确认的修改计划修订，另存新版本并保留原稿。
请核对权项引用、说明书支撑及版式，最后说明使用了哪份修改依据。
本次不送评、不提交申请。
```

### 解释新报告

```text
使用 $patent-evaluation-revision。
这是复评报告和实际送评文稿，请对齐新旧权项，解释哪些分项发生变化，
哪些修改有改善证据、哪些仍不能确定。先解释，不继续改稿。
```

## 运行条件与授权

Skill本身提供工作流指令，不包含评分引擎或评估平台连接。实际执行依赖宿主环境的文件读取、检索及文档处理能力；修改DOCX时还需可用的渲染和视觉检查能力。

不虚构实验、准确率或提分结果，不靠机械换词或增加弱权项凑分。送评、付费、提交申请及公开材料，均须有相应授权。
