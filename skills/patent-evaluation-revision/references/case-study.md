# 一次10星到11星修订的经验边界

这是2026-10-30一次已核对报告与文稿的脱敏案例，仅用于示范分析方法；不是评分系统说明书，也不是未来项目的事实证据。不保存当事人姓名、联系方式、私人文件路径或完整未公开稿件。

## 实际结果

| 指标 | 修订前第三次报告 | 修订后第四次报告 |
|---|---|---|
| 综合 | C级10星 | B级11星 |
| 可专利性/技术竞争/市场前景 | 2/3/5星 | 3/3/5星 |
| 系统低风险项 | 1/10 | 3/9 |
| 主权项风险 | 66% | 63% |
| 整体近似度 | 64.33% | 59.91% |

原10项经技术修改并单列一个从属项，形成11项完整版；另存9项方法评估版，删除程序产品和终端两项。第四次报告展示的9项权利要求与该评估版一致。没有对同一修改稿的11项版和9项版做受控复测。

## 哪些变化有报告证据

- 新权3单列分支适用关系，相关度52%，成为新增低风险项；它是从属项，不是法律意义的独立权利要求。
- 新权6对应旧权5，相关度约54%→52%，继续低风险；新报告存在两条52%的匹配记录。
- 新权7对应旧权6，相关度65%→50%，跨入低风险；两次匹配的是同一对比文献的相同片段。
- 新权5对应旧权4，67%→69%；新权8对应旧权7，67%→68%；新权9对应旧权8，71%未变。
- 原主权项主要匹配对象改变，但旧对象仍位于附录首位，报告相似度74.64。不能解释成已排除该文献。

低风险组的51.5%与四条匹配记录52、52、52、50的平均一致，不是三个低风险权项等权平均。仅凭这点仍不能推出最终评分权重。

## 可复用的经验

1. 将“某个对象/关系发生变化时，具体谁失效、谁保留、为何”写成可检查动作，比泛列状态、版本和校验模块更能说明区别；是否导致降分仍看实际报告。
2. 有针对性的修改要进入真实权项及说明书，不能只存在于计划。把新旧项按内容映射，才能找到改善和恶化。
3. 对比全文会推翻过宽的创新说法。该案发现对方已有历史留存、不同依赖类型、局部复用和版本回滚，因此把区别收紧到组合如何改变行为，而不是换术语。
4. 删项改变参评集合，但没有对照实验不能量化其贡献。按旧标签静态删除两项风险项，只得到低风险1/8；实际3/9还包含新增/改写项的变化。
5. 参考11星样本曾有正文10项、系统统计11项的误拆；检测时间也不同。不能用它推导“低风险达到某比例就必得几星”。

## 不应迁移成通用规则

- 不固定使用9、10或11项，不保证删除类别就升星。
- 不把60%作为通用风险阈值，不把3/9作为3星公式。
- 不默认所有加分来自可专利性；每次重新读分项。
- 不要求其他领域采用该案的分支、两类引用、账本、规则索引或一次回退。
- 不把该案的11星写成已达12星、已授权、已证明技术优于全部现有方案。

可支持的归因是：技术细化、权项组织与参评集合变化共同发生，并伴随可专利性跨档；具体评分因果仍未被分离验证。
